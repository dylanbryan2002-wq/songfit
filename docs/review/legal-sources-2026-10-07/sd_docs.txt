Introduction
The MassiveMusic API is organised around REST. Our API has predictable resource-oriented URLs and uses standard HTTP response codes, authentication, and verbs.
Our APIs returns JSON and XML responses, dependent upon on the request header specified.
HTTP headers
accept: application/json
accept: application/xml
Access to MassiveMusic services is provided through a REST style interface.
The base URL for the MassiveMusic API is located at the following address:
BASE URL
https://api.7digital.com/1.2/
What is the MassiveMusic Platform?
Use the MassiveMusic Platform to access music catalogue data, deliver audio and artwork, and support playback, reporting, and enrichment workflows in your product.
Problem it solves
The platform gives you a single REST API surface for working with catalogue, delivery, playback, and reporting services instead of building separate integrations for each capability.
Who it's for
The platform is for developers building music-enabled products and services that need to work with catalogue data, audio delivery, streaming, reporting, or metadata enrichment.
What you can build
You can use the platform to build:
Download services
Streaming services
Subscription streaming services
Interactive radio streaming services
Background music services
Fitness services
Social media services
Content delivery services
Applications that use catalogue events, standard metadata, enhanced metadata, artwork, or embedding data
📘
References to 7digital
Please note MassiveMusic previously traded as 7digital and all API endpoints operate under 7digital domains. These URLs are all valid and part of the current production platform. There are currently no plans to migrate to a different domain.
